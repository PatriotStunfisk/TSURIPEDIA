# 検索流入と回遊の改善 — 2026-09-26

## 選定根拠

Search Consoleの実画面から、[20ページの基準値](./search-growth-2026-09-26.json)を記録した。28日フィルターだが、チャートの表示期間は2026-09-17〜23。133クリック／3,124表示／CTR4.3%／平均順位12.6。移行直後・少数のデータなので、月間収益や将来の順位を推定する数値には使わない。

当初の「8〜30位」に機械的に限定せず、表示されているのにクリックが少ないページと、すでにクリックのある具体的な料理・釣り場を選んだ。人気ランキングとしてサイト上には表示しない。

## 実装

- 料理10本：魚名だけを入れ替えた要約を具体化。8本に下処理・仕上げの3ポイントと失敗対策表を追加。既存のニジマス・サッパの工程図と説明は維持。
- GUIDE4本：堤防テンヤ重量、タモ長、10月大阪湾、アミエビ量。結論・タイトル・説明を検索意図に合わせ、二列の判断表と手順を追加。既存の模式図・仕掛けコンポーネントを再利用。
- 釣り場6地点：船宿・釣り堀は集合港、便、調理受付など計画に必要な情報を補完。撫佐・千丈ヶ滝・武庫川は既存の図解・確認情報を維持し、冒頭の要約と導線を改善。
- 次に読むリンクは理由付きの2〜3件を優先。既存の4件目以降も折りたたみ内に残す。表示待ちの操作制限や新しい外部JSは追加しない。
- 料理情報は魚種ファイル、GUIDEは既存記事、釣り場は既存の詳細データに置く。別のSEO用ページや重複URLは作らない。
- descriptionは本文と同じ要約を使用。canonical・hreflang・既存URLは変更しない。

## 比較方法

公開直後の順位変化を成果とは扱わない。次の比較では同じURL集合・ウェブ検索・国/端末条件・同じ日数を揃え、クリック、表示、CTR、平均順位を確認する。まずデータの揃う連続7日で比較し、28日が揃ってから長期評価する。季節需要、曜日、インデックス移行の影響を分けて考える。

Vercel Web Analyticsの既存ページ閲覧数は利用できるが、今回の特定リンクのクリック率や読了率を直接示すものではない。独自クリックイベントの収集は今回追加していない。回遊効果はまずページ/訪問と入口・遷移先ページの閲覧を同条件で比較し、厳密な導線別評価が必要ならプランとプライバシー設計を確認した上でイベント計測を追加する。
