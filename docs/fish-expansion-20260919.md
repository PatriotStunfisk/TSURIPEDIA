# MAP対象魚からの魚種拡充（2026-09-19）

## 追加内容

チカ・ウミタナゴ・シログチ・マガレイ・ホッケ・クロガシラガレイ・コマイ・ニシン・エゾメバル・キビレの10種。魚図鑑は86種から96種へ。各魚種の基本情報・見分け方・生態・釣り方・安全情報・捌き方・4料理をプロフィールへまとめ、既存レジストリからmetadata・sitemap・MAP・QUESTへ接続する。トップの基本10種は変更しない。

MAPの対象魚名から635件の地点×魚種の関係が新たに解決する。釣果投稿が635件増えたという意味ではない。全体では8,224件中7,354件を接続。`node scripts/audit-map-fish.cjs`（JSON出力は `--json`）で未登録名と掲載地点を確認できる。カレイ・ソイ・カジカ等の総称を特定の一魚種に無理に紐付けない。未接続名は引き続き残る。

## 画像

組み込みimage_genで魚体10枚、料理40枚を個別生成。魚体は `public/images/fish/<slug>-profile-20260919.webp`、料理は `public/images/cooking/<slug>-<recipe>.webp`。魚体は透過の左向き全身図鑑写真風、学名・体形・模様・各ひれの特徴を指定し、文字・背景・切り落としを除外。料理は各魚と料理名を明示し、家庭の自然な和食写真風、器・調理状態・切り身形状を料理ごとに指定。別魚種の画像は流用しない。全50枚を目視確認し、WebPへ変換。共有用JPEG60枚は既存export-sharingから不足分のみ生成。
