# 海岸・港の追加確認（2026-09-21）

200地点を追加。既存2,388地点から2,588地点へ。37都道府県を対象に、公開釣り場案内と地理院地図の海岸線・岸壁を照合した。現地確認済みや管理者の許可取得済みという意味ではない。

無名に近い護岸・河口は位置の分かる地形名で表示し、公式施設名を創作しない。禁止の記載が見つからないことだけで釣り可能とは判断せず、釣り利用の参考情報がある候補に絞った。駐車場・トイレは未確認のため設定していない。転載写真・転載本文は使用していない。

## 除外と制限

酒田北港の立入禁止区画、復旧状況と利用範囲を特定できない能登の港、閉鎖情報が残る候補は今回は除外。既存地点との同名・近接も確認し、南あわじメガフロートなどの重複候補を除いた。投げ釣り禁止・夜間禁止・季節規制は個別の注意欄に残した。別県の同名漁港は都道府県名を付けて区別する。

- [石川県・漁港等の復旧情報](https://www.pref.ishikawa.lg.jp/suisanka/notohantoujishin/notohantoujishin.html)
