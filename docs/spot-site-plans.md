# 釣り場の現地マップ・ポイント図

- 日本語の釣り場個別ページは既存座標を利用した周辺地図を表示する。図のない場所も対象。地図は画面に近づいてから既存Leafletを読み込み、全国の地点データを渡さない。
- `lib/spot-site-plan-data.json` は施設ごとの模式図・アクセス・ポイント解説。現在7施設（平磯、尼崎、南港、とっとパーク、熱海港、若洲、鳴尾浜）。全2783地点の地形を実地確認済みという意味ではない。
- 公式の施設図・アクセス案内と釣行記事を照合する。ブログ・メディアは地形や探り方の参考に使い、現行の禁止事項は運営案内で更新する。記事・写真・元の図を転載せず、確認した事実を元に独自の図を作成する。
- `shapes` と `labels` は640×340の模式図座標。緯度経度ではない。上から見た図、断面、足場比較の区別を `orientation` に明記する。魚礁や駐車場の正確な位置が未確認ならGPSピンを作らない。
- ポイントの魚・釣法は既存slugのみ。名称は `spot-site-plans.ts` が既存レジストリから解決する。誤ったslugはテスト・buildで検出する。
- `spotFieldGuides` に結合し、個別ページとMAP詳細が同じ解説を表示する。MAP初期表示に全解説を積まず、既存の地点別guide APIで選択地点だけ取得する。小さいプレビューには図や長文を追加しない。
- 追加時は出典・確認日、駐車場／公共交通／トイレ、到着後の動線、狙う層や構造、季節、回収方向まで記入する。未確認の水深や設備を推測しない。
- PCと390px幅で地図タイル、図中リンク、文字の重なり、魚・釣法リンク、既存の釣果表示を確認する。
