# 港・堤防の追加調査（2026-09-18）

約200地点の依頼に対し、位置と岸釣り情報を照合できた189地点を追加した。従来749件から938件へ（閉鎖等38件を含む）。船宿と計画エリアは今回の追加数に含めない。

## 調査方法

- 釣り広場の個別ページで対象魚・足場・制限を確認。文章・写真を転載せず、個別の要点を執筆した。
- Googleマップの地物ピンを候補として地理院地図の岸壁・波止と照合。別県の同名港、町域中心、事務所や港の中央水面のピンをそのまま採用しない。
- 個別の釣り情報と地理院地図の参照先は各レコードの `sources` に保存した。
- 確認日は公開資料の照合日であり、現地踏査日や釣りの許可取得日ではない。ピンは代表位置であり、利用許可範囲を示さない。
- 未確認の駐車場・トイレ・最新料金は推測で埋めない。「ソイ」「サバ」などから特定の魚種を推定しない。
- 同じ港の意味のない分割は行わない。別地域にある同名港には所在地を補足した。

## 主な除外・制限

- 山形県の港湾・漁港：県の2026年回答を踏まえ、今回の岸釣り追加には採用しない。[県の回答](https://www200.pref.yamagata.jp/020026/kensei/joho/kocho/namanokoe/2026nen/5gatsu/0810220.html)
- 能登：震災前の紹介記事だけでは追加せず、復旧後の利用範囲が不明な候補は除外。[石川県の復旧案内](https://www.pref.ishikawa.lg.jp/suisanka/notohantoujishin/notohantoujishin.html)
- 富山：女良・国分・宮崎・富山新港外堤等の禁止候補、滑川の利用区画を特定できない候補は除外。岩瀬・魚津・入善では外側の制限を港内側と分けて明記。
- 福井：鷹巣の規制図と岸壁を照合。防波堤上・消波ブロック・作業区画に誘導しない。[県の規制図](https://www.pref.fukui.lg.jp/doc/etizen/tachiirikinshi.html)
- 長田港：古い釣り場記事と現在の禁止情報が食い違うため除外。
- 白杉：短い堤防・外側先端の立入制限を明記。タコ採捕への導線は追加しない。
- 町域中心や別港を返したピンは除外。曲港を潮の浦港、小奥戸を奥戸として二重登録しない。
