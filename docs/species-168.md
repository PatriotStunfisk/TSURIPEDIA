# 20-species expansion: 148 → 168

Reviewed 2026-09-25. Existing IDs, images and original catalogue order are preserved.

## Authoring

Each species uses its canonical profile in `lib/fish-species`. Compatibility views, related links, cooking routes, metadata and QUEST still derive from the registries. English overlays use the same species IDs. No GLB model was invented; the existing 2D fallback and 3D preparation notice remain.

Each of the 20 species has four cooked recipes (80 total), preparation steps and an individually generated matching dish image. Freshwater preparation does not recommend self-assessed raw consumption. Catfish recipes specify food-suitable prepared fish. The tenjikudai profile uses ネブト / メブト and does not confuse it with the キンギョ nickname of nenbutsudai.

Three method pages and three focused guides cover catfish topwater hook timing, approved Biwa salmon trolling and kokanee depth/soft-mouth handling. Equipment plans deliberately distinguish dedicated or rental tackle from universal accessories; no unsuitable rod was added merely to fill six slots.
