# 魚図鑑の3D操作

- `lib/viewer-navigation.ts` が通常の図鑑ビューアの操作を担当する。
- マウス：ドラッグで回転、ホイールで拡大縮小。移動モード、Shift＋ドラッグ、右ドラッグで平行移動。
- タッチ：1本指は選択中のモード、2本指はピンチで拡大縮小しながら平行移動。
- `＋` / `−` はマウス・タッチ・キーボードで押せる。倍率は0.5〜3倍。
- 「初期位置に戻す」で倍率・平行移動・回転と操作モードを戻す。魚種ごとの元モデルの向き・サイズ・照明は維持する。
- `components/ViewerControls.tsx` を共通利用。読み込み中・失敗時は操作ボタンを表示しない。
- 既存7魚種の専用ビューアを維持。QUESTの `swim` モードには図鑑用の操作を追加しない。
