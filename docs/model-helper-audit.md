# 3D補助キューブの除外

`lib/model-presentation.ts` で確認済み28ファイルだけを対象にする。`Cube_2` という名前だけでは削除しない。

条件は単独メッシュ、非スキン、14または24頂点、全頂点のXYZが ±1 の単位キューブ。条件が異なれば残す。GLB原本は変更しない。

- 既存専用ビューアは従来のカメラ計算後に非表示化し、構図を維持する。
- 共通ビューアは検証済み補助物のみ取り除いて魚体の枠を計算する。
- タチウオは補助物除外後も頭が切れないよう魚体全体を収める表示を指定する。
- アマゴの `cube_NewUVs2` とニジマスの `BoxGizmo001` は魚本体・骨格なので除外しない。
- 28ファイルのGLB構造検査、同名の非キューブを残すテスト、既存7魚種の実表示を確認する。

新しいモデルを対象に加える際は、名前だけで推測せず、GLBの子メッシュ・スキン・実頂点・マテリアル共有の有無とブラウザ表示を確認する。
