# 100魚種・生態ビジュアル・関西釣り場（2026-09-19）

## 内容

- 96種から100種へ：カツオ、マダラ、スルメイカ、スナガレイ。各種に背景透過の魚画像、4料理・画像、捌き方、見分け方、安全情報、釣法、GUIDE、QUESTパラメータを登録。
- 生態ビジュアルを8種追加：マダイ、ブリ、シロギス、チヌ、メバル、マハゼ、コイ、スルメイカ。合計16種。共通コンポーネントの画像下の再現画像ラベルはユーザー指定で削除。生態の参照リンク・alt・画像サイズ・遅延読み込みは維持。
- 魚図鑑：基本順・五十音順・初心者向け順・今月のシーズン順。GETフォームで検索条件と並び順をURLへ保持し、追加のclient JSなしで利用可能。シーズンはプロフィールの月データによる目安で、地域別の釣果ランキングではない。
- 関西6釣り場・3船宿追加、MAP総登録2333地点。プロフィールと同じ魚・釣法レジストリを利用。
- トップページの基本10魚種・既存URL・既存画像・3Dモデルを維持。新規4種は2Dフォールバック。

## MAPの位置・再開確認

新規地点の出典は `lib/fishing-map-kansai-reopening.ts` に保存。地図を表示して海岸線・波止・港内と照合し、住所や駐車場中心から水際へ補正した。

- かもめ大橋下：ユーザー提供の https://www.instagram.com/p/DauDz8oP8t0/ を実画面で確認。2026年7月の補修完了・開放・階段設置報告を採用。駐車場なし。古い大阪市回答の工事閉鎖を現在の閉鎖と扱わない。橋の道路中央ではなく白灯のある南西側波止へ配置。
- 南芦屋浜：2026年8月2日フィッシングマックスの東護岸開放報告を採用。南護岸の制限と混同せず北側東護岸を登録。
- 花市場公園・なぎさ公園：2026年の釣具店現地報告と案内図を照合。通常の護岸であり「海釣り公園」分類にしない。
- J-GREEN：2026年渡船利用の釣行記、形状を示す空撮、地理院地図を照合。陸側にピンを置かず、約10m離れた独立波止へ配置。陸からの無断進入を案内しない。
- りんくう公園：公園管理者が内海の釣りを禁止。南側マーブルビーチの外海側を登録し、北側内海や園内全体が釣り可能と扱わない。
- 八千代丸：公式アクセス地図KMLの座標と樽井漁港の乗船場を照合。
- 湊丸：公式乗船図と岡田浦漁港の岸壁を照合。公式はHTTPで稼働、同ホストのHTTPSは証明書名不一致。未確認のHTTPSへ改変せず、テストの既存HTTP許可ホストに追加。
- 夢フィッシング：公式渡船図・アクセス図から、出島漁港の乗船側へ配置。

## 二色浜の調査結果

砂浜・海浜緑地・二色運河を混同しない。二色運河は登録済み。砂浜の投げ釣りは釣り場資料で確認できるが、管理者の2026年9月8日避難指示に伴う一時封鎖告知と9月12日以降の営業案内が併存し、釣りに使える範囲の再開告知は確認できなかった。今回、恒久閉鎖と断定せず、砂浜の新規通常掲載は見送り。管理者による現在の利用範囲の確認後に追加する。

- https://nishikinohama-park.com/news/ （9月8日封鎖・その後の施設営業情報）
- https://www.taikobo.net/place/map/pdf/sensyu2.pdf （砂浜・海浜緑地の釣り情報）
- https://nishikinohama.osaka.jp/play_in_nishiki/beach/ （海水浴の利用期間）
