# 2026-09-18 MAP追加の確認記録

今回の検証済み追加は157地点（船宿146、岸の釣り場11）。全登録は592→749、既存の閉鎖情報38地点を除く通常表示は711。依頼の約400地点追加には未達で、未確認候補を公開件数へ含めていない。

- 日本海側：富山8、石川8、新潟11、福井20、鳥取4。
- その他：青森1、山形1、福島1、神奈川30、千葉21、茨城5、三重3、岡山5、和歌山1、山口4、徳島2、香川5、福岡11、佐賀4、長崎2、熊本6、広島4。
- 地点ごとの確認先・確認日・座標の意味は `lib/fishing-map-autumn-growth.ts` の `sources` / `verifiedAt` / `positionNote` に保存。
- Google地図の表示中心を乗船場所と取り違えず、公式アクセスの目的地ピン・乗船場所KML・公開座標を使用。受付位置しか確認できない場合は本文に明示。料金や出船時刻は固定しない。
- 新潟西海岸第1〜第5突堤は県の2026年開放図と地理院地図を照合。それぞれ数百m離れた独立突堤。夜間禁止と期間開放を記載。
- 金沢港大野・大浜、富山新港4護岸は公式の釣り可能区域図と地理院地図を照合。公園の中央や隣接する作業岸壁へ置かない。
- 別業種へ転用されたドメイン、閉業情報、同じ施設の別名は候補から除外。
- 同名の船宿は港名を添えて識別。15m以内の船宿は個別事業者の同じ港の案内地点。既存の重複座標マーカー分離を利用し、座標そのものを架空の位置へ動かさない。
- 魚の別名は `getFishByName` で一意に解決できる場合だけ図鑑へ接続。「青物」のような総称から特定魚種を推測しない。
