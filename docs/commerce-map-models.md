# 商品導線・実地図・追加モデル（2026-09-15）

## Amazon商品リンク

ユーザーの明示的な依頼に基づき、公開ストアID `uolink-22` を使用。アカウントへのログイン、認証情報の保存、商品API、価格・評価・商品画像の転載は行わない。

`lib/affiliate-products.ts` に商品ID・対象釣法・用途・購入前の確認点を集約。魚ページは既存の釣法関係から商品候補を取得する。釣法の合わない魚には商品枠を出さない。PR表示、Amazonアソシエイトの識別文、`rel="sponsored noopener noreferrer"` を共通コンポーネントで付ける。

商品候補はAmazon.co.jpの公開ページで確認。価格と在庫は掲載せず、選択肢のある商品は購入先でサイズ等を確認するよう案内する。商品名検索を大量に並べる仕組みではなく、確認済み商品のみ登録する。

- [Amazon公式：ASINによる商品リンク](https://affiliate.amazon.co.jp/help/node/topic/GP38PJ6EUR6PFBEC)
- [Amazonアソシエイト・プログラムのポリシー](https://affiliate.amazon.co.jp/help/operating/policies)
- 各商品の確認先：`https://www.amazon.co.jp/dp/<登録ASIN>`（確認日をレジストリに保存）。購入・カート追加・成果発生のテストはしない。

## 地図と現在地

Leaflet 1.9.4でOpenStreetMap標準タイルを表示。既存の登録座標だけをピン表示し、選択は一覧・詳細へ連動する。地点選択だけではズームをリセットしない。座標未登録の項目は一覧で扱う。範囲を推測して釣り可能地点として表示しない。

現在地はボタン押下時にブラウザへ取得を依頼。Reactの画面状態だけに置き、直線距離順の計算に使う。保存・自社サーバーへの送信・地図への現在地送信は行わない。許可拒否・タイムアウト・非対応時も地域名検索を利用できる。「現在地の利用をやめる」で座標を破棄する。

地図画像は外部のOpenStreetMapから読み込む。表示中の登録地点周辺のタイルが要求され、ユーザーの正確な現在地をタイル中心には用いない。標準ブラウザキャッシュを使い、タイルの一括取得・先読み・オフライン保存は実装しない。著作権表示を地図内に残す。

- [Leaflet公式クイックスタート](https://leafletjs.com/examples/quick-start/)
- [OpenStreetMapタイル利用方針](https://operations.osmfoundation.org/policies/tiles/)

## 追加GLBの確認と補正

- クロダイ：`chinu` → `kurodai.glb`、マイワシ：`iwashi` → `maiwashi.glb`。標準名のファイルがあればそちらを優先。
- 最新のユーザーアップロード `590623f` をfast-forwardで取り込み。`isaki.glb`・`kanpachi.glb`・`nijimasu.glb`はこの版を優先する。ルートにある旧ファイルは削除しない。
- 旧`isaki.glb`はカンパチと同一内容だったため、既知の誤ファイルのハッシュだけを検出して2Dへ戻す保護を追加。最新の別内容のイサキは通常どおり有効になる。
- 一部スキャンに付属する`Cube_2`は色見本。確認済み8ファイルだけ、読み込み後のシーンから取り除きGPU資源を解放。GLB自体や魚体メッシュは変更しない。
- 最新ニジマスは現行の材質形式。初期表示を正面から側面へ回転する。旧版向けに試した互換処理は不要となったため、最終実装へ含めない。

既存7魚種のモデル設定・専用デザイン・本文・画像・URLは維持する。
