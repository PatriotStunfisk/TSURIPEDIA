# 10魚種の完成版への拡張

対象：スズキ、クロダイ（chinu）、マイワシ、カンパチ、イサキ、マアナゴ、アユ、ニジマス、アマゴ、マゴチ。

9種は既存プロフィールへ追加し、マゴチだけを新規登録。既存URL・本文・画像は維持。図鑑は26エントリー、本格プロフィールは23種、料理は92レシピになった。既存の地方名・成長名のURLは統合・削除していない。

## 登録する場所

- `lib/fish-species/<slug>.ts`：基本情報、詳細、見分け方、調理準備、4レシピ、画像、釣法ID、関連魚、GUIDE ID、QUESTの挙動。
- `lib/fish-species/index.ts`：新規魚だけ一度登録。既存の簡易魚を昇格するときは不要。
- 新しい釣法が必要な場合はmethod registryへ登録。釣法ページとGEARのタックル一覧へ反映する。
- GUIDEは記事として執筆しall-guidesへ登録。魚プロフィールのIDと記事内の魚リンクから双方へ接続する。
- 実在の釣り場は公式情報と確認日を持つMAPデータへ登録。ゲーム環境から実釣許可を推定しない。

新規50画像の生成記録・SHA-256は `species-batch-10-images.json`。料理画像3点は下処理と一致するよう生成し直した。既存の画像は変更していない。

## QUEST / 3D

10種すべてが共通プロフィールからQUESTへ参加。淡水3種には清流・管理池を指定し、海へ誤出現させない。アユは縄張りを守る行動として表現する。

`media.modelTilt` はモデルの初期X回転角（ラジアン、省略時0）。ヒラメにπ/2を指定し、薄い側面からではなく体形が見える方向で表示する。魚図鑑とQUESTが共有し、GLBファイル自体は変更しない。

GitHubに追加されていたヒラメ・サワラ・マダコのGLBはfast-forwardで取り込んだ。今回の10種のGLBは未提供。正式2D画像を表示し、同じslugのGLBが追加されれば次のビルドから3Dが有効になる。

## 次の改善候補

河川・ルアー釣法の誘い操作をさらに具体化する。追加10種のGLB整備、公式情報で裏付けられる魚別釣行先、料理写真の継続的な監修を進める。魚種の追加数だけを目的に内容を薄くしない。
