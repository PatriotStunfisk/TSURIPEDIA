# GUIDE 705 / fish 122 expansion

This batch adds 200 Japanese articles: 10 species identification/fishing guides and 190 focused QUICK GUIDE questions. The existing 505 articles and their URLs remain unchanged. Five initially drafted topics were replaced because the existing library already covered the same question.

Questions cover omorig, vertical boat ajing, hitotsu-tenya, basket float fishing, tip-run, octopus egi, tilefish, deep-water rigs, medai, ishidai, ayuing, carp, freshwater float fishing, rockfish lures, surf lures, boat whiting, ajing, cooking and tackle specifications. Each has a diagnosis, three actions, a two-column decision table and a full GUIDE parent. Methods and fish references use the existing registries. These editorial choices are not measured search-volume claims.

New species: murasoi, takenokomebaru, kuromejina, chidai, matoudai, akayagara, hachibiki, chigodara, himeji and kanagashira. Each has identification, habitat, fishing, safety, preparation and four illustrated cooked recipes. English encyclopedia overlays and language-route registration are included. No new GLB models are supplied; the existing 2D fallback remains available.

Species reference URLs are recorded in each profile and its corresponding GUIDE. Chidai uses Evynnis tumifrons rather than the older Evynnis japonica name. Takenokomebaru includes a conservation note with the Fukuoka biodiversity reference. The broad common name ソイ is deliberately not assigned to a single new species. Marine donko is not conflated with freshwater donko.

Image provenance is in species-122-images.json: 10 original transparent fish assets and 40 individually generated dishes, converted to WebP (about 6.4 MB in total). Each dish was checked against the selected recipe. 260 missing JPEG sharing cards were generated with the existing script; no existing images were removed or overwritten.

Validation: TypeScript, ESLint, full tests (257 passed), production build and responsive browser checks. Homepage featured species and existing route IDs remain unchanged.
