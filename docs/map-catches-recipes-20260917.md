# MAP・釣果・料理画像の検証（2026-09-17）

## このまとまりで実装した内容
- 釣り場タイプをスマホ3列の複数選択へ変更。初回は全タイプON、店舗OFF。タイプ・店舗レイヤーと地図表示範囲を同一セッションで保持する。
- 釣具店を釣り場と別レジストリで7店舗登録。公式店舗案内・地図を照合し、未確認の餌在庫等は未確認と表示。オレンジの四角マーカーで区別する。
- 釣り場から `?near=<slug>&shops=1` で30km以内の店舗へ移動。距離は直線距離であり、営業時間・在庫は公式確認へつなぐ。
- 釣果の基本入力を魚・匹数・日付へ整理し、写真と詳細は任意。「その他」「魚種不明」、餌、重量・指幅を追加。保存後に同じ釣り場の自分の最近の釣果へ表示する。
- 代表料理の画像不足52件（40魚種）を個別生成で補完。代表最大4品と既存URLを維持し、既存画像は削除しない。共有JPEGも料理画像へ更新。
- MAP検証スクリプト `node scripts/audit-map.cjs` でID・名前・座標・近接重複・都道府県・分類を監査する。既存の座標未確認8件は警告として残し、推測で埋めない。
