# Approximate prefecture outlines

Source: https://github.com/amay077/JapanPrefGeoJson (Data of Japan, public domain per upstream README).
Retrieved 2026-09-17. Geometry simplified to approximately 0.008 degree tolerance, rounded to 4 decimals; small rings retained.
These are geographic orientation aids, not current legal boundaries, fishing permissions or maritime jurisdictions.
Loaded on demand only when a region/prefecture filter is selected.
